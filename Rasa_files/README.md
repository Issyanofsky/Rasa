This folder contains all the essential Rasa project files used in the guide:
* __actions.py__ for custom Python actions.
* __config.yml__ for the pipeline and policies configuration.
* __domain.yml__ defining intents, entities, slots, and responses.
* __endpoints.yml__ to configure the action server.
* __nlu.yml__ with training examples for natural language understanding.
* __rules.yml__ and stories.yml for dialogue management, and any other supporting files.
Together, these files form a complete Rasa project structure that was followed step by step in the guide.
